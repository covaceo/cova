# Session recap artwork

Bundled New York-inspired, London-inspired and Tokyo-inspired architecture generated with OpenAI image generation for this approved Cova feature. These are illustrative backgrounds, not contemporaneous photographs or evidence of a trading date. All financial/identity text is rendered by the application from the selected account. No text is baked into these images. The unmodified generated masters remain outside the public repository. Local custom photos are decoded and re-encoded in the browser, never uploaded.
